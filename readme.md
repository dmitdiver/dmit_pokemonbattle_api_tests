# Pokemonbattle API Tests

Проект содержит автотесты для API https://api.pokemonbattle.ru/v2.

## Структура проекта

- `tests/` — тесты API.
- `helpers/` — вспомогательные функции для подготовки данных.
- `conftest.py` — общие pytest-фикстуры.
- `constants.py` — базовый URL, ID тренера и токен.
- `pytest.ini` — регистрация pytest-меток.
- `requirements.txt` — зависимости проекта.

Код разделён так, чтобы тесты оставались короткими и понятными, а повторяющаяся логика была вынесена в отдельные функции и фикстуры.
